# FINDU 0.8.7

Windows x64 实时工作区修正版，重点为多路启动的错误反馈、启动过程与操作范围。包含 0.8.6 产品更新修复，沿用同一 IPSPOS 引擎；实时增量协议、1 Hz 刷新、缓存容量和算法未更改。

- 批量启动时，单路准备配置失败也会保留错误并继续处理其余方案，不再因准备请求异常中断整批。
- 创建进程前失败的方案显示“启动失败”和原因，详情同步显示；错误不再仅靠短暂弹窗。各行提供“启动此路 / 重试启动”。
- 原生状态尚未刷新时保留方案行与选择，显示“正在启动”，避免成功提交后短暂消失或切换到另一方案。
- 方案按名称中的编号稳定排序，不随原生随机会话 ID 重排。
- 批量按钮显示本次可启动数量，详情按钮明确标注“仅启动当前方案 / 录制”。批量反馈汇总成功与失败数量，减少弹窗堆叠。
- 未启动、停止接收、等待状态更新与已连接计数分开显示，不将停止会话保留的旧心跳当成当前连接。

先导入多个 OPT，勾选要运行的方案，再点击“启动所选方案”。下方详情及行内按钮仅操作当前一路。某路失败可查看原因、修改后单独重试，其他路继续运行。

现场报告的“只有第一路启动”在 0.8.6 五份原始 TEST 配置的短时实测中未复现：五路均成功启动并接收历元。因此不能把本次发现的交互与错误处理缺陷认定为该现场现象的唯一原因。具体测试见 VALIDATION-0.8.7.md。

本次只生成 Windows 包；未重新构建 Linux。完整解压后运行 FINDU.exe。程序未签名，需 WebView2 和 Microsoft Visual C++ 2015–2022 x64 Runtime。
