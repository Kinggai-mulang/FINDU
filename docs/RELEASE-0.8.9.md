# FINDU 0.8.9

产品对比的轨道参考点增加“自动判别 / 保持原值 / 去径向常量”。新产品默认自动，旧版本保存的勾选与未勾选状态仍对应原来的手动处理，避免升级后悄悄改变结果；可自行切到自动。

## 判别与显示

自动模式先比较原始轨道差异，再结合 HAS/B2B 转换来源或 SP3 文件名中的 HAS、B2B、SSRA 线索与数值稳定性判断。WHU/CHC 提供方名称本身不作为 APC 证据。证据不足显示“待确认”，保留原值。计算后每组输入框显示实际处理及依据，改动设置立即清除旧结果，重新计算后才可导出。CSV 增加处理方式、判别依据和逐星去除的径向常量（cm）。

保守数值门限：共同历元跨度至少 1 小时；每个系统至少 6 颗卫星各有至少 12 个径向样本；径向均值的中位数绝对值在 0.5–3 m，逐星标准差中位数不超过 0.15 m、且均值绝对值大于其 5 倍；星间均值绝对离差中位数不超过 0.35 m；径向偏移大于切法向合成 RMS 中位数的 2 倍；至少 80% 卫星偏移同号。全部系统均通过才对这一组逐星去径向常量。这些是工程启发式门限，不是官方 APC 判定标准，不会为单组测试数据放宽。

## 四组真实样本

使用 `TEST/PRODUCT_COMPARE/5_matched_2026-10-18` 的 WHU、CHC、HAS、B2B 和 WUM 最终参考。自动结果：WHU/CHC 保持原值，B2B 去径向常量，HAS 待确认并保持原值。HAS 的 GPS 星间径向均值离散超过门限，可手动选择去径向常量复核。样本和旧版验证记录保留。

## 适用范围

“去径向常量”沿用现有逐星平均偏移消除方法，并非 ANTEX 加卫星姿态的物理 APC→质心转换，可能同时去掉真实的常量轨道误差。自动状态明确标为推断，不表示已证明输入采用哪种参考点。严谨精度评估需检查原始结果及来源约定，不能直接用消除偏移后的 RMS 证明绝对精度。

来源依据：[IGS RTS 产品说明](https://www.igs.org/rts/products/) 区分 SSRA/APC 与 SSRC/CoM；[Galileo HAS SIS ICD v1.0](https://www.gsc-europa.eu/sites/default/files/sites/all/files/Galileo_HAS_SIS_ICD_v1.0.pdf) 描述 HAS 的参考点约定。[IGS SSR 格式](https://files.igs.org/pub/data/format/igs_ssr_v1.pdf) 同样区分参考点。通用转换 SP3 头可能丢失原始来源，故不把文件扩展名或产品提供方当确定性证据。

引擎、实时会话、DCB/ANTEX 下载管理和 PPP 参数未改变。本版为 Windows x64；解压完整目录后运行 FINDU.exe。
