# FINDU 0.8.11

产品对比新增“清空参考产品”和“清空对比产品”。两侧独立操作，清空对比产品后保留一个空白产品框，重置对应的参数与转换输入；不会删除磁盘文件。之前的结果随输入变更失效，尚未结束的文件夹导入或转换不会重新填回已清空的产品。

下载页明确显示“当前程序的本地存储位置”，说明目录随程序位置自动创建、缓存由当前程序的多个任务复用。未读取到路径或浏览器预览时不显示拼接的假路径。下载目录不是固定到开发者电脑；看到测试目录名是因为程序当时位于该目录。

删除后处理页依赖开发者绝对路径的“载入本次两个验收案例”入口。通过“导入多个 OPT”、拖入文件或新建配置开始使用。运行目录解析、引擎和下载工具的资源查找不再依赖编译机器上的源码路径。

将完整发布包解压到有写入权限的目录，运行 FINDU.exe。首次启动会在程序旁创建 runtime，保存任务、缓存和设置；升级时保留自己的 runtime 可继续使用原记录。不要分发个人 runtime；正式 ZIP 不包含测试记录、导入路径或用户设置。

引擎与 0.8.10 相同，本次不改 GNSS 解算或产品对比算法。
