# FINDU 0.8.1 本地构建

流畅度与细节优化版本，不增加新功能。引擎仍为 IPSPOS BetaV0.611，GNSS Log=4 / StatusLog=1 不变。

## 流畅度

- **实时仍为逐秒刷新，传输改为增量。** 0.8.0 每秒复制、传输并比较整段缓存（最多 3600 历元及诊断、产品、日志），运行越久越慢。现在只传新增历元，长时间运行与刚启动时开销相同。6 路实时对比在定位页的主线程占用由 94% 降至 15%。
- **长结果分析不再卡死。** 47 小时、1 Hz 的两份后处理结果（共约 34 万历元），在 0.8.0 绘制定位图时页面卡死。现在约 1.5 秒显示，诊断页签单次卡顿由约 1.3 秒降至约 0.4 秒，内存约为原来的三分之一。
- **长序列显示抽稀，只影响绘制。** 超过 6000 点的序列按像素列保留首、末、最高、最低点，尖峰、解状态变化和缺口不会丢失。放大到 6000 点以内自动显示全部历元。实时缓存（不超过 3600）始终完整绘制。长结果在分析页可切换“自动抽稀 / 全部历元”。统计、事件和导出始终使用全部历元。
- 界面各区域只订阅自己需要的数据，实时更新不再带动整个程序重绘。

## 界面细节

- 多结果对比时，图例只显示区分各方案的部分（如 `KIN` / `STA`），不再出现被截断、分页的长文件名，也不再与纵轴单位重叠。
- 纵轴单位统一放在轴的上方；纵向缩放滑块更细，配色统一。
- 交互提示（滚轮缩放纵轴、Shift + 滚轮或底部滑块调整时间、点击图例筛选）每个视图显示一次，不再在每张图下重复。
- “卫星详情”页签点开即显示，不再需要再点一次展开；只在该页签打开时订阅，离开后释放。

## 其他

- 删除开发演示模式（模拟监控、模拟后处理及其示例数据）。所有页面均为真实 IPSPOS 路径；浏览器预览只显示界面。
- 代码统一格式化（Prettier / rustfmt），ESLint 无告警。新增 `CLAUDE.md`，记录架构、不变量与验证方法，便于后续由 AI 维护。

测量方法、具体数值和回归范围见 [验证记录](VALIDATION-0.8.1.md)。
