# FINDU 0.8.6

本次为 Windows x64 产品准备流程修正版。引擎与 0.8.5 相同，解算协议、算法、实时数据传输和图表没有变更。保留 0.8.5，可并行使用。

- 数据与下载页区分主配置就绪、DCB 仍在准备、可用但有缺项、使用有效缓存但未确认版本。显示 DCB 产品有效期、保持截止与最近检查时间。
- 自动 DCB 每次准备时检查适合观测日期的近期发布产品，校验同频通道关系与时段；优先读取 CAS 发布目录，避免未发布日期耗尽下载预算。网络失败可回退至有效缓存，但不再显示成已确认最新。指定本地 DCB 则固定使用，便于复现。
- 天线继续按参考框架选择，每 24 小时检查官方版本；保留 IGS14 与 IGS20 的区别。指定本地 ANTEX 则固定版本。
- 去掉根据候选文件数推算的下载百分比，保留实际已校验数量。清除已结束记录不会取消仍在准备的 DCB。
- 项目维护脚本 `scripts/update-test-products.py` 可更新外部 TEST 的天线和 DCB 路径，分别匹配实时与历史观测，保留不可变产品快照；只备份产品字段，不复制实时连接凭据。

“可用”表示通过相关校验，不表示每种可选产品齐全，也不保证发布中心已发布今天的产品。产品更新只影响后续导入：已导入的 OPT 或运行中会话需要停止并重新导入，才会使用新文件。

本次仅生成 Windows x64 包；Linux 本次没有重新构建验证。完整解压后运行 FINDU.exe，保留同目录 engine、product-tools、product-runtime。Windows 需要 WebView2 Runtime 和 Microsoft Visual C++ 2015–2022 x64 Runtime。程序未签名。

版本与测试范围见 VALIDATION-0.8.6.md。IGS 天线文件使用原则见 [IGS Antenna Working Group](https://www.igs.org/wg/antenna/)。
