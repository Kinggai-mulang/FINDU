# FINDU v0.7.6

Windows x64；运行引擎维持 IPSPOS BetaV0.604。

## 实时指标

- 实时诊断范围栏补充完整 UTC 日期、实际跨度及覆盖日期数；跨午夜时能够区分前后两天。
- 顶部明确显示“搜索 Ratio / 固定卫星”，并附 AR 未通过、确认中、成功等状态。Ratio 是本历元整数搜索的比值，未固定时仍可能有效；是否发布已确认固定应看 FIX / HOLD 及 FixS / FixA。
- 无观测、无搜索约束或 AR 关闭时不展示搜索 Ratio。缺测显示“—”，真实计数 0 保留。
- 解算日志停更后显示“历元停更”，隐藏顶部当前指标并提示检查数据流；完整历史和图表保留，恢复后自动更新。采用本机实际收到诊断的时间判断新鲜度，支持历史回放；超时阈值结合配置与近期实际历元间隔，避免真实 5 秒观测被 1 秒配置误判。
- 停止的会话标注“末历元解状态”；状态流停更或会话停止后不再显示旧接收速率。
- 源码分发补齐 Python .pyd 运行扩展；打包时自动检查下载模块可启动。
- 同一会话更换配置重启后，实时看板按会话身份绑定，不会被旧配置草稿错误隐藏。

## 运行

完整解压后启动 FINDU.exe，保留 engine、product-tools、product-runtime 等目录。需要 WebView2 与 Visual C++ x64 运行库。程序未签名。运行数据与可能含连接凭据的运行配置位于程序旁 runtime，不能上传到公共仓库。
