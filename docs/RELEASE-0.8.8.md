# FINDU 0.8.8

产品对比修正版，包含 0.8.7 的多路实时修复。引擎与轨道、钟差、偏差计算算法未改变。

- 选择北斗后切换到只有 GPS 的产品，不再丢失当前系统筛选项；无匹配数据时明确显示产品与系统，仍可查看其他产品的同系统图表。
- 某组偏差失败后，自动符号提示按产品名称匹配，避免错挂到其他产品。同名产品无法唯一对应时不显示推断提示。
- 修改文件、名称、参考点或符号参数后清除旧结果，并忽略旧请求的迟到响应；重新计算期间禁止导出旧结果。
- 当前查看偏差、但偏差全部失败时，自动显示仍然成功的轨道钟差结果；反向情况同样处理。
- HAS、B2B 缺少相位偏差时仍保留产品卡片，标明无该类可比数据。轨道提示默认显示四条，可展开全部。
- 轨道“覆盖率”改为“参考匹配率”，界面和 CSV 名称一致，说明该比例不是整段连续供给率，也不是所有产品共同样本覆盖率。

同期样本位于 IPSPOS 的 `Data/TEST/PRODUCT_COMPARE/5_matched_2026-10-18`：`reference_WUM` 为参考，`products` 下 WHU、CHC、HAS、B2B 分别添加为四组。完整说明与文件哈希位于样本目录。该目录的数据不包含在程序 ZIP 中。

本次为功能与界面回归，不作产品精度排名；WUM 最终产品是参考产品，不是无误差真值。Windows 包完整解压后运行 FINDU.exe，旧版本与运行数据保留。
