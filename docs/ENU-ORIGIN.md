# FINDU 0.7.1：ENU 显示与原点

实时定位、后处理历元监看、实时对比和后处理对比采用同一个定位图表。

1. 在 E/N/U 三行、ENU 叠加或 EN 轨迹中，点击一个定位点。
2. 上方出现所选方案、UTC、XYZ。点击“将选中点设为原点”。
3. 各方案均用该 XYZ 重新计算 ENU；选中点为零。点击“恢复默认原点”返回原坐标口径。

此操作仅改变显示坐标。独立参考、PRIDE 参考、RMS、收敛判定、CSV 与报告继续使用分析设置中的参考；图上持续说明这一边界。相对基线位置差是向量差，保留分析参考坐标系，不作为绝对位置重新归零。

切换原点保留当前时间缩放，坐标范围重新适配。实时追加历元、缓存淘汰选中点后仍保留所选 XYZ；新运行或更换方案集合清除旧选择。没有有效 XYZ 时禁用选点重算；有缺失 XYZ 的方案在重投影时仅显示可计算历元，并显示提示。

叠加模式以实线圆点 E（东）、长虚线菱形 N（北）、点线三角 U（天）区分方向，上方有线型标识；悬停显示方向、米、方案与原始解状态。单方案仍按解类型着色，FIX/HOLD 合并；多方案仍每个文件一种颜色。

EN 轨迹起终点使用 8 像素小三角、1.5 像素描边与深色填充，位于曲线上层：绿色上三角为起点，红色下三角为当前终点。说明放在图例区域，图中不再显示起终点文字。标记来自当前保留或筛选的数据窗口，实时刷新，区别于固定解的浅绿色曲线。

软件、窗口、页面和报告显示名改为 FINDU。已有工程目录、内部 Rust 包名、存储键、Tauri 应用标识、脚本名和 FINDYOU_* 桥接环境变量保留兼容，不要求移动工程或迁移原配置。相邻 IPSPOS 源码、OPT 和正式引擎未修改。

0.7.1 用 design/brand/icons/findu-icon-dark.png 生成 Windows ICO 和界面图标。叠加图稀疏显示方向标记，避免密集符号遮挡虚线；不抽样删除历元，悬停与点击选点仍使用全部数据（最近 9 像素内定位点），隐藏的图例曲线不参与选点。
