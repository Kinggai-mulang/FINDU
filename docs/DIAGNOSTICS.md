# PPP / RTK 诊断分析预览

新版入口：`deliverables/diagnostics-preview/FINDU.exe`。保留整个目录的配套组件后运行；应用版本仍为 0.7.3。本轮只修改 FINDU 前端、分析与导出，没有修改相邻 IPSPOS 源码、引擎二进制、Rust 接入代码，也没有提交 Git 版本。

上一轮可运行入口仍为 `deliverables/log4-adapter/FINDU.exe`。两个目录独立保存各自的运行数据和界面偏好，可以关闭新版后直接打开上一轮程序查看旧效果。

## 使用方式

1. 实时监控载入原有 OPT 后启动，或在后处理完成后点击“查看结果”，也可从分析对比导入已有会话目录／Log=4 日志。
2. 保留原有 ENU 三行、叠加、EN 等比例轨迹和显示原点选点。单方案沿用解状态颜色；多方案每份结果一种颜色。新增诊断图中，多方案同文件同色，不同字段采用不同线型。
3. 根据日志头区分 PPP 和 RTK。混合结果的专属诊断可按算法切换，定位对比继续使用原有同站分组和参考口径。缺少模式元信息的真实结果不推测为 PPP。
4. 所有新增诊断图可以独立缩放纵坐标；滚轮调整纵轴，Shift＋滚轮调整时间。共同时间窗和鼠标时间指示用于核查同期现象。图例可以筛选曲线；单击曲线点或状态带可展开同历元证据。
5. 实时提供 5／15／30 分钟和缓存全段。手动调整时间后显示“固定时间窗”，后台继续接收，点击“恢复实时跟随”恢复滚动。在线缓存最多 3600 历元，停止后可从输出目录导入完整记录。

## PPP 大气与状态耦合

| 分区 | 内容 |
| --- | --- |
| 状态与更新 | ZWD、TrpSRMS、IonDRMS、发布状态 Q 和 AR 确认 AC；可展开 ZHD 模型 |
| 状态耦合 | ZWDUCor、IAC50／95、同历元 Up、卫星支持及接受更新 |
| 事件核查 | 按可调 IonDRMS 显示阈值组织连续段、保留峰值及同期 QC／重置；跳到前后 60 秒 |
| 分布与统计 | 字段有效数、缺测、实际零值、最小、中位数、时间 P95、最大；当前时段或 UTC 半小时窗口；按最终发布状态分组、按字段有效交集比较 |

采样口径沿用最新 IPSPOS：当前 AR／HOLD 前的接受浮点状态，既往 HOLD 已进入先验。最终 FIX／HOLD 标签用于分组，不把大气字段称作“固定大气解”。

- ZHD 使用 m，为干延迟模型。ZWD 原始 m，界面 mm；合法负值保留。
- TrpSRMS 为协方差传播得到的形式不确定度；IonDRMS 为频率槽 0 的后验减预测更新 RMS，排除新建／重置／基准变化样本。它们都不是有独立真值验证的大气误差。
- ZWDUCor 是湿延迟与局部 Up 的有符号形式相关，范围 −1～1，−1 为合法值。
- IAC50／95 为“所有接受模糊度已知”条件下电离层方差消减比例的星间中位数／P95，范围 0～1；不是固定率、相关系数或实际 PAR 子集收益。
- 默认显示完整范围；阅读窗只改变显示并标记越界值，鼠标仍能查看原值，统计和事件不删尖峰、不补零。时间缺口和被排除的历元断线。
- 半小时窗口按 UTC 整点／半点划分，右端点属于下一窗口。IAC95 的时间 P95 是对逐历元星间 P95 再统计，不是全星历元混合 P95。

## RTK 专属模块

- **共视与差分**：Obs／Com、UDS、SDS、DDS 分别展示，再核查 FloIn／FloUse、DOP、重置及拒绝。DDS 不含参考端，FloUse 包含参考端，不能将这些计数当成严格递减漏斗。
- **基站与同步**：BRAge、同历元两端解算坐标间距、当前基站局部 ENU 基线、基站坐标相对当前窗口首个有效坐标的变化、已记录基站 ECEF。BRAge 是两站观测时差，不是网络延迟；几何间距和坐标变化不是独立真值误差。
- **数据源与同步**：ROVE、BASE 两张卡，区分实际接收、停滞、重连与错误。后处理显示原始输入或保存的状态快照，不将历史状态当作当前网络状态。
- **模糊度与固定**：Q／AC 状态、Ratio、ADOP、CanA／SchA／InstA／FixA、候选与发布卫星、PCR、候选残差、ADR。AR 关闭时明确标注，不以 0% 固定率评价固定能力。FIX 与 HOLD 统一为固定颜色，原始状态仍保留。
- **后验残差**：PPP 非差行与 RTK 双差行分别解释。码残差使用 m，相位残差使用 mm，ADOP 保留 0.0001～1 对数显示和原始值。
- **独立测速**：位置页内提供 VQ、ECEF 速度、速度模长、卫星支持与观测行数；VQ 独立于位置 Q，预测速度不当作有效测量速度。

## 导出与目录

“导出原始诊断 CSV”导出当前诊断算法、时间窗和样本集合的原始字段，保留日志单位及新增列；ZWD、FLRMS 等仍为 m。指标 CSV、当前可见图 PNG 和独立 HTML 报告继续提供，HTML 增加 PPP 大气／RTK 同步图表及统计。

新版默认输出和缓存位于 `deliverables/diagnostics-preview/runtime/`；开发运行位于工程 `runtime/`。本轮验证记录位于 `runtime/diagnostics-20261021/`，没有把测试结果写入 IPSPOS 或 C 盘。

当前接口没有逐星大气和完整基站信号明细，也没有独立大气真值；本轮不生成逐星热图、TEC／ROTI 或自动因果结论。产品状态仍沿用 IPSPOS 的时效规则，接收 UTC 与观测 GPST 分开核查。
