# FINDU v0.7.5

正式版，Windows x64 便携程序。引擎 IPSPOS BetaV0.604，协议 GNSS Log=4 / StatusLog=1。本次小版本更新修复显示、统计性能与实时会话缓存；解算引擎二进制保持一致。

## 更新内容

- 多天曲线统一采用 UTC 日期与时间刻度，展示完整时间范围及覆盖日数，跨午夜与 GPS 周切换时能够区分日期。
- 大气半小时统计改为单遍分桶，减少长数据集反复扫描。
- 后处理运行预览只保留最近 300 条，结束后加载完整结果，避免轮询传输整个累积结果。
- 离开实时页面保留会话、配置与统计，后台继续接收；不可见的明细停止传输，返回后重新同步。
- 分析页只在选中对应实时结果时传输实时对比数据；浏览历史归档保留实时缓存。
- 明确移除已停止实时方案时释放关联结果、明细与编辑草稿；运行中方案仍需先停止。原始数据与结果文件保留。

## 使用

完整解压后启动 FINDU.exe，保留 engine、product-tools、product-runtime、engine-tools 和文档。需要 WebView2 与 Visual C++ x64 运行库，程序未签名。

后处理：在“数据与下载”选择观测文件和产品策略，检查覆盖与警告，再导入生成的 OPT 运行；也可导入已有 OPT。结果进入分析对比，时间统一以 UTC 展示。

实时：新建方案、配置数据源并启动。切换页面不会清空会话；停止后可保留结果，明确移除则清理内存状态。仅录制模式不执行定位解算，不生成定位统计。

所有运行数据默认位于程序旁 runtime；程序目录须可写。live.opt 可能含连接凭据。更新时使用独立新目录，保留旧目录和所需结果，不直接覆盖运行中的程序。build-info.json 和 engine/manifest.json 提供应用、引擎版本及 SHA-256 校验信息。

## 验证和限制

完整十五天观测与实时持续回放验证见《VALIDATION-0.7.5.md》（源码仓库 docs 内）。测试未发现随已测时长持续增长的卡顿，但不代表已证明数周或无限时运行无增长。外部产品缺测仍会影响可解算性；此次没有独立真值精度结论。
