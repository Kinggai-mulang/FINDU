## 范围与限制

实时集成测试通过回环地址使用录制流，观测与产品原文未修改，采用加速传输。旧 RTCM 流只携带周内秒，离当前时刻超过半周时可能按系统日期初始化到相邻周；首轮旧时段测试出现此现象，改用同一完整录制的较新末段后通过。历史回放应使用有可靠日期的后处理入口，不能把错误周数的无解解释为定位精度下降。

公网实时数据源连接未执行：自动审批拒绝读取配置凭据并连接未明确授权的 NTRIP 服务器。本次没有声称完成公网连续长测、16 路墙钟一小时长测、16+32 路同时持续运行、独立真值精度验证，或任意硬件下的吞吐保证。十五天用例沿用既有产品，原有缺测与覆盖警告仍适用；FLOAT/FIX 计数不能替代精度评价。

测试输出、原始数据、连接配置、缓存、编译源码和中间文件留在本地，不进入 Git 或正式便携压缩包。发行包保留引擎清单、应用构建记录及使用说明，便于复核与回退。
