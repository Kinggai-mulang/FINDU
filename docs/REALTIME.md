“搜索 Ratio / 固定卫星”分别表示本历元整数搜索比值和已确认固定的卫星数；失败或确认中的搜索也可能有 Ratio。无观测、无搜索或 AR 关闭时显示缺测。诊断停更后隐藏当前指标，历史保留，恢复后更新；停止后标注末历元。新鲜度按本机收到诊断的时间判断，结合实际采样间隔，支持历史回放。状态心跳冻结后接收速率归零。

# FINDYOU 0.4.0 实时与图表说明

## 0.4 多路运行与分析（替代下文旧版单路范围）

同时运行最多 4 路，每路独立 IPSClient、目录、缓存和停止控制；最多保留 16 路会话/方案。可载入多个 OPT，核对方案名称、测站与观测分组后批量启动。列表支持单路详情、单路停止、批量停止、打开目录及移除终态记录。移除记录不会删除原文件。

产品对比的主要路径为：同一份 HC RTCM3 观测分别配 SSR / B2b；HX10 混合流来自同站不同接收机或天线，单独归组。分组依据由用户核对，界面不根据相同站名推断观测相同。选择同组的两路后可进入实时对比；缓存最多 3600 条，明确显示滚动缓存口径。停止后从完整目录打开，使用完整日志分析。跨站可同时监控，分开分析。

真实公网短测已观察到 HC/SSR、HC RTCM3/B2b、HX10 混合观测/B2b 的 PPP FLOAT。HAS 1002 / WHU_UBX_X20 能握手，但独立直连及应用测试仅收到 ICY 200 OK，无后续产品字节；用户正在检查源端。本版不宣称 HAS 实播验收通过，也不把 HAS 方案的 SPP 定位当作 HAS PPP。

「分析对比」新增产品覆盖页，读取现有 JSONL 的 1 Hz 产品状态快照，显示各方案轨道、钟差、码/相位偏差的时效有效数量与最新 age。该页使用接收到达 UTC，独立于定位的 GNSS 时间窗；0 与未提供严格区分。时效有效不是所需产品完整或解算正确的证明。完整逐星/逐信号产品发布审计仍待单独实现。

结果索引保存在 runtime/config/analysis-index.json；成功后处理和结束的实时会话自动登记，可重启后按需打开，不会自动连接。界面凭据只保留本次内存，私有 OPT 和运行副本含凭据，不随交付包发布。

## 使用

打开 Windows 版，进入「实时监控 → IPSPOS 实时解算 → 数据源与配置」，载入 IPSClient-HC.opt，或直接拖入一个 OPT。核对定位模式、SSR / B2b / HAS、NTRIP 各流、天线、初始星历缓存与本地输出，然后启动。

常用参数使用表单，未展示的 GNSS 参数沿用原 OPT。可选偏差/大气流以挂载点是否为空决定启用；地址与凭据留空时按原 IPSClient 规则继承主产品流。切页不会启动第二个接收进程。

界面偏好不保存用户名和密码。凭据仅保留在本次界面内存和必要的运行副本 live.opt 中。看板隐藏含连接凭据的日志行，正式报告不包含凭据。

停止后保留曲线和诊断缓存；磁盘保存运行配置、原生输出、清单与摘要。执行状态不跨应用重启恢复。

## 图表

默认 E/N/U 三行，共享 UTC 时间轴；可切换叠加与 EN 轨迹。

- 图内滚轮 / 拖动缩放、平移坐标；Shift + 滚轮 / 拖动调整时间，底部滑块选择时间段。各方向右侧有独立坐标滑块，可输入上下限。
- 检查中的实际时间与坐标边界随新增历元保持；「重置视图」恢复范围。
- EN 使用相同的米/像素比例，滚轮同时缩放两轴。
- 单结果按解类型着色，FIX/HOLD 共用绿色固定解，FLOFIX 单列。原始状态保留在提示和统计中。
- 多文件对比每文件一种颜色；叠加用实线 E、虚线 N、点线 U 区分方向。

有独立参考时填写 GNSS_RefPoss（ECEF 米坐标）。留空或 0,0,0 时以首个有效定位为原点，表示相对变化，不能视为独立真值误差。

## 产品与指标口径

接收线程在锁内发布连接状态、HTTP 拒绝码、累计字节、最近到达、RTCM 帧/HAS 页、重连尝试与产品队列计数。速率由相邻 1 Hz 快照差分计算。

按轨道、钟差、码偏差、相位偏差及星座汇总已解码卫星、时效有效卫星、有效信号、最新 GPST 历元与 age，同卫星多信号不重复计星。

时效检查调用 IPSDLL 现有源类型规则，不另设阈值。age/时效以本机当前时间为基准；时效有效不等于广播星历匹配、所需信号齐全、AR 资格或定位正确性。

OC 是配置排除后、高度角过滤前实际轨道钟差支持卫星数；FloatIn 是进入 PPP 更新的卫星数，FloatUse 是被接受更新使用的卫星数。这些量以实际观测历元为基准。

产品解码沿现有观测时间线推进，排队帧不冒充已解码。无观测时心跳仍更新，已有产品 age 继续增长。历史录制流的当前墙钟时效可以为零，而在历史观测历元仍产生 PPP，两个基准分开显示。

Log=2 提供解状态、卫星数、DOP、后验残差、周跳、重置、Ratio、FixS、FixA。-1 缺测、-2 溢出显示未知，实际 0 保留。AmbR 等原日志未提供的量不造数。

运行日志增量读取控制台与 ULog，可搜索、筛选并跟随最新。ULog 等级/文件过滤继续生效；定位指标独立读取逐历元日志，不受该等级限制。

## 隔离与缓存

FINDYOU 启动独立 IPSClient 进程。运行副本强制关闭 RTIE_bSendSolDB、RTIE_bSiteInfoFromDB，各会话使用独立星历缓存，原 OPT 与输入保持只读。正常停止关闭接收与日志；连接长时间不返回时，8 秒后结束进程。Windows Job 在应用退出时回收子进程。

定位、逐历元指标、产品历史各最多 3600 条，运行日志最多 500 行，当前显示最多 300 行。文件按偏移增量读取，处理末尾半行、截断与覆盖，单次最多 1 MiB。缓存统计不宣称覆盖整场会话，完整日志留在磁盘。

IPSPOS 仓库只增加可选 FINDYOU_MONITOR_FILE JSONL 输出、FINDYOU_STOP_FILE 请求、接收线程快照和只读时效查询；公式、阈值、状态迁移及产品消费顺序不改。监控不清除标记、不额外推进队列，也不再次调用产品桥接。

## 范围与验证

本轮支持单站 PPP 动态/静态。SSR/B2b/HAS 配置已映射；本版 IPSClient 对 B2b/HAS 关闭 AR，界面明确说明。MADOCA/CLAS 原生解码未实现，界面禁用。B2b/HAS 尚无真实设备流验收。

产品多方案对比、下载文件完整离线审计、产品自动下载、数据库与网关不在本轮范围。

早期 IPSClient.opt 主产品挂载点返回 HTTP 404；新提供的 HC 配置启用 BIAS 流 EPH 后，公网测试已有真实 PPP FLOAT、卫星数、DOP 与 ENU 曲线。HC 的观测流未提供广播星历，BIAS 流的 1019/1042/1046 必须启用 EPH 才会解析；不能用“接收字节非零”代替星历可用性。详情见 deliverables/fixes/ACCEPTANCE.md，旧阶段证据保留在 deliverables/phase3。


## 本地目录与诊断提示

默认结果、缓存和导出集中在工程 runtime 下，后处理为 postprocess，实时为 realtime。每个会话单独保存 live.opt、日志、产品缓存与原始结果；live.opt 含连接凭据，请勿作为公开附件。WebView 与偏好在 cache/webview；程序子进程临时文件在 cache/temp。

定位看板明确区分：尚未发现日志、日志已读取但无有效 XYZ、日志解析异常。固定数量 0 正常绘图；未提供的 DOP 显示“—”，不填 0。解算类型与 GNSS_ARMode 可在顶部选择，修改对下次启动生效，运行中禁用。
