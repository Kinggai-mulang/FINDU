# FINDU 0.8.1 验证记录

0.8.1 不增加功能，只做流畅度、代码结构与界面细节优化。引擎仍为 IPSPOS BetaV0.611（GNSS Log=4 / StatusLog=1），二进制与 0.8.0 相同。

## 环境

Windows 11 Pro，Intel Core Ultra 9 285K（24 线程），95 GB 内存，WebView2 156。对比对象为同一台机器上的 0.8.0 便携包与 0.8.1 构建，两者使用相同的 engine、product-runtime 目录。

## 性能对比

## 真实数据流

使用 `IPSPOS/Data/TEST/RTIET` 的 `Alloy-WHU.opt` 与 `Alloy-HC.opt` 同时实时运行约 3.5 分钟：

- 已读历元每秒加 1（145 秒内 5 → 150）。
- 每次增量读取 4–9 KB；0.8.0 每秒读取完整缓存，随运行时间增长到数 MB。
- 两路实时对比的时间窗每秒前进 1 秒，无页面错误。
- 全部停止后两路状态为 stopped。
