# FINDU 0.8.0 本地构建

引擎升级为 IPSPOS BetaV0.611，保持 GNSS Log=4 / StatusLog=1。此目录为本地构建，尚未发布到远端。

本机验收通过：16 路连续 30 分钟逐历元结果与原始引擎一致；单会话和 16 路重复处理耗时对照均未超过 2% 目标。此前差异来自回放时序与产品队列溢出，未更改解算算法。测量方法、具体数值及硬件边界见验证记录。

- DCB 只提供文件框，支持拖入、浏览、粘贴和清空。启动前校验；为空或不可用时运行副本写 OFF 并继续，合法文件写 ON。用于 SSR 同频码偏差转换，文件通过校验不代表已参与本次算法。保持期默认 15 天，导入 OPT 的合法设置保留。
- 产品准备接受 RINEX、RTCM3、Unicore 和原生引擎支持的混合观测。只有确实缺少完整日期才要求补 GPST 日期。纯 UBX RAWX、只有导航或改正的流不可作观测。
- 主产品就绪即可导出或送入后处理。DCB 在独立队列尽力准备，支持本地、缓存及按观测日期下载；失败、离线或超时不改变主产品状态。详情可单独重试 DCB。
- 后处理增加 CLAS L6、格网、网络编号、GPS 周、首帧 TOW 及 PPP-RTK 大气参数；保留导入的 POLY 和时间窗口。实时 CLAS 仍遵从引擎能力限制。
- 结果按 Log=4 内容发现，兼容带 CaseName 的新文件名和大写扩展名。多个候选结果由用户选择；预览、导入、历史保存实际日志路径。
- 实时会话的“卫星详情”提供星座频点数量、放大的天空图和载噪比图；PRN 在卫星标记内，北斗中国红、星座旗帜图例、水平频点标签和清晰数值，可按星座、频点、单星筛选。最多 1 Hz 更新，只有展开时订阅；收起、切换或隐藏页面后释放，不保存逐星历史。状态不确定显示未知，不沿用上一历元。诊断由启动器环境变量管理，不在 OPT 中加入字段。

完整解压后运行 `FINDU.exe`，保留 `engine`、`product-tools`、`product-runtime`。不依赖 IPSPOS 源码目录。测试范围和性能证据见 [验证记录](VALIDATION-0.8.0.md)。
