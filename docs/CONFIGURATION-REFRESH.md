# 配置与速度显示调整

本轮仅修改 FINDYOU，不编译或修改 IPSPOS，不提交或更改版本号。

- 删除 PRIDE 页面、任务服务、参考解自动关联、专用工具和打包依赖。历史结果文件保持原样。IPSPOS 的手动参考 XYZ 和 REF 输入继续可用。
- 后处理按 PPP／RTK 显示文件组。RTK 使用流动站、基站、广播星历、参考文件与基站坐标；精密产品及 PPP 天线项隐藏。实时配置同样隐藏 PPP 专属选项。
- OPT 拖入配置区域；单个文件拖入对应路径卡片。所有路径卡片共用一个 Tauri 文件拖放监听器，按实际区域、优先级和 DPI 分发。错误文件不会覆盖原字段。RINEX O／导航按文件头识别，不能仅凭 `.rnx` 后缀判断。
- 直接解算的压缩观测需先通过“数据与下载”准备／解压；该页面仍接受 `.gz`。广播星历缓存接受已有文件夹。
- 新生成 OPT 不再写入 `GNSS_bUsePPPOSB`、`GNSS_bAddTropGrad`；导入已有 OPT 仍保留原参数。AR 是否启用继续使用 `GNSS_ARMode`。
- ENU 速度使用同历元流动站 ECEF 位置计算椭球纬度、经度，只对引擎 VX／VY／VZ 做旋转。与位置图的显示原点无关，不对轨迹差分，不要求 Q 已固定；测量速度仍要求 VQ ≥ 2。
- 东／北／天速度单位 m/s。水平速度 `sqrt(VE²+VN²)` 与三维速度 `sqrt(VX²+VY²+VZ²)` 在同图显示。若缺少有效位置，仅三维模长仍可显示。预测值、缺失值保持缺测。
- 原始 XYZ 速度不覆盖；诊断 CSV 同时提供原始字段和派生 ENU／模长字段，速度单位均为 m/s。

源码快照和验证记录放在 `runtime/config-refresh-20261022/`；新交付与旧版分开存放。
