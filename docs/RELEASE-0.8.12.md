# FINDU 0.8.12

产品对比中，只有一个对比产品时也能直接修改名称；从多组删除至一组后仍可改名，刷新后保留。名称编辑不再与“移除这一组”按钮绑定。

北斗卫星筛选移除按 PRN 划分的 BDS-2/BDS-3 分组，只提供实际轨道已判定的 GEO、IGSO、MEO 类型。只有一种已知北斗轨道类型时也显示其按钮。北斗系统标题和逐星选择保留，便于与 GPS 等系统区分；未知类型不按 PRN 猜测，提示补充覆盖时段的有效 SP3。

沿用已有轨道分类：由 SP3 位置序列估算惯性系速度、半长轴和轨道倾角；当前工程阈值为半长轴大于 35000 km 时按倾角小于 10° 区分 GEO，否则为 IGSO，其余为 MEO。分类是 GNSS 产品筛选的近似判定，不是卫星身份或官方轨道类型目录；没有足够连续历元时不分类。本版未改变该算法或引擎。

将完整发布包解压到可写目录，运行 FINDU.exe。升级时可保留自己的 runtime 数据；正式 ZIP 不含测试运行记录或个人设置。
