# FINDU 0.9.0 验证记录

日期：2026-11-04。Windows x64 与 WSL Ubuntu 22.04 原生 Linux x64 构建。

## 引擎一致性

Windows PE 与 Linux ELF 引擎分别从 IPSPOS 干净提交 `64690b4` 编译，版本 BetaV0.615，源码 SHA-256 `53d2e53375a48853c4bb962f6e35768eab03301a3f147ffa0d21f5c668d1f083`。两端 build_id、提交、源码摘要、协议与能力声明一致，各平台二进制摘要独立核验；替换前的引擎保留在本地备份中。

Log=4 / StatusLog=1 未变；源代码差异为版本号和 PPP 固定解接受目标卫星数门限。原始观测与产品只读，发布包不含测试数据、运行目录或凭据。

## 验证范围

- Windows/Linux 各通过前端 23 个文件、135 项测试，以及 TypeScript、ESLint、Prettier 检查。
- Rust：Windows 113 项、Linux 114 项通过，各有 4 项需外部输入的测试默认忽略；实际数据通过下述原生集成入口另行执行。
- 两端均通过引擎更换工具 3 项、可选产品逻辑 8 项测试；随包 Python 的观测识别、用户日期、gzip 输入、本地 HTTP/curl 下载及钟差校验通过。
- 两端原生适配回归各完成静态 PPP-AR、动态 PPP-AR 与 RTK 三个后处理案例，解析到 2880、2880、3305 个历元；各完成 16 路本地 NTRIP 实时会话、2 路录制会话及 2 次重启。验证进程调度、Log=4/StatusLog=1 解析、卫星快照、正常停止与索引，不把历元数量当精度证明。
- Windows 正式便携包实际加载 WHU/WUM 轨道钟差并完成对比，单组改名、刷新保留和 IGSO 筛选通过；批量启动错误隔离、两侧清空、产品状态和本地 ANTEX/DCB 的浏览器回归通过。
- Linux 原生 GTK/WebKit 正式包以非 root 用户在 Xvfb 下打开实时监控、后处理、数据与下载、分析对比、产品对比五页，无页面异常或横向溢出；实际运行离线产品准备任务为 ready，运行目录跟随搬移后的程序。Xvfb/WebKit 的五次截图请求均超时并按既有测试策略跳过，页面 DOM 与真实 IPC 功能断言全部通过；本次不宣称完成 Linux 像素级视觉检查。
- Windows 与 Linux 原生构建、随包运行依赖、平台文件头、引擎清单和哈希检查通过。ZIP/tar.gz 只包含程序和固定资源，不包含 runtime、个人输入、缓存或连接凭据。

本地运行证据位于 `runtime/release-090`，Linux 原生运行证据另在构建机 `/tmp/findu090-native`、`/tmp/findu090-desktop`。发布资产附带 SHA-256 清单及本验证记录。
