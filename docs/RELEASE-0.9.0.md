# FINDU 0.9.0 — Windows / Linux 同步发布

本版汇总 0.8.6–0.8.12 的产品准备、实时批量启动、产品对比和可移植性改进，统一提供 Windows x64 ZIP 与 Linux x64 tar.gz。

## 更新内容

- 实时多方案批量启动：修复配置准备异常会中断后续方案、启动失败反馈不清晰的问题，逐项报告结果，失败的方案不会阻塞其他方案。
- 产品准备：明确下载中、缺失、校验失败、缓存回退与更新未确认状态；本地 ANTEX/DCB 分别配置，清空路径恢复自动选择，按观测时段与参考框架检查适用性。
- 产品对比：参考与对比产品分别一键清空，单个对比产品也可改名；修复输入变更、失败产品与结果显示的问题。
- 轨道参考点默认自动判别，证据不足保持原值，可手动覆盖。逐星去径向常量不是完整 ANTEX 改正，应保留原值复核。
- B2b 转换显示实际轨道/钟差系统覆盖，缺北斗时提示匹配 B-CNAV1 星历。
- 卫星筛选移除按 PRN 划分的北斗代际，只使用 SP3 推断的 GEO/IGSO/MEO；未知类型不猜测。相位偏差页明确同信号交集和整数性质解释限制。
- 清理开发机测试入口和编译机路径依赖；默认存储位置按实际程序所在目录生成。

## 内置引擎

两个平台均来自干净提交 `64690b4a3aa336cfe3d76bf08bc565c2e775da1c`，版本宏为 **IPSPOS BetaV0.615**，源码 SHA-256 为 `53d2e53375a48853c4bb962f6e35768eab03301a3f147ffa0d21f5c668d1f083`。

本次引擎调整固定解的发布门限：按实际接受的非参考目标卫星计数，至少满足 4 颗及配置的最少卫星数。Log=4、StatusLog=1 和既有可选输出能力保持不变。固定解发布数量可能因此变化，不应把降低的固定率直接解释为显示错误。

## 安装与升级

- Windows：完整解压 ZIP 后运行 FINDU.exe，需 WebView2 和 Microsoft Visual C++ 2015–2022 x64 运行库。
- Linux：x86_64、glibc 2.35+，需 GTK 3 / WebKitGTK 4.1。Ubuntu 22.04 可安装 `libwebkit2gtk-4.1-0 libgtk-3-0 libayatana-appindicator3-1 librsvg2-2 xdg-utils curl gzip`，在 Linux 文件系统内解压 tar.gz 后执行 `./FINDU`。
- 升级前关闭旧程序及其解算进程，将完整新包解压到可写目录。需要旧记录时复制自己的 runtime；不要把旧 engine 或 product-tools 覆盖回新包。
- 发布包不包含个人设置、连接凭据、测试数据和历史运行结果，不需要另装 Python。

程序未签名；不提供 ARM64、Alpine/musl 或 AppImage。验证范围及限制见同包 `VALIDATION-0.9.0.md`。
